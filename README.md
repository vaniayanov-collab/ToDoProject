
# ToDoProject

Невеликий навчальний проєкт для роботи зі списком завдань на Python.

## Можливості
- додавання завдань;
- перегляд списку завдань;
- видалення завдань;
- пошук завдань.

## Структура проєкту
- `src` — програмний код;
- `tests` — тести;
- `docs` — документація;
- `.gitignore` — файли, які Git не повинен відстежувати.

## Запуск
Для запуску програми виконайте:

```bash
python src/main.py
```
